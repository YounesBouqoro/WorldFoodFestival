# World Food Festival – Kassenrechner

Mobiler Kassenrechner für das World Food Festival 2026.

## Aktueller Stand

- Standauswahl als Startseite
- Drinks-Kasse mit allen Preisen aus der aktuellen Getränkekarte
- Kategorien für Softdrinks, Red Bull, Bier, Aperitif, Wein, Longdrinks und Pfand
- Mengensteuerung per + / −
- 25 % Studentenrabatt per Button
- Pfand wird nicht rabattiert
- Pfand +2 € und Pfandrückgabe −2 € separat erfasst
- Responsive Bedienung für Smartphone, Tablet und Desktop
- Struktur vorbereitet für weitere Food-Stände

## Dateien

- `index.html` – Standauswahl
- `drinks.html` – Drinks-Kassenansicht
- `styles.css` – World-Food-Festival-inspiriertes Design
- `app.js` – Produkte, Preise, Warenkorb und Rabattlogik

## Weitere Stände ergänzen

Für neue Stände kann eine weitere Standseite angelegt werden. Das Produktsortiment sollte jeweils separat gehalten werden, damit die Kassenoberfläche pro Stand schnell und übersichtlich bleibt.
